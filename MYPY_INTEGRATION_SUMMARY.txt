HOW TO USE
================================================================================

FOR DEVELOPERS (Before Committing):

1. Install MyPy (first time only):
   pip install mypy numpy

2. Run type checking locally:
   python check_types.py

3. If errors appear, review and fix:
   - See MYPY_SETUP.md for error explanations
   - Fix type hints or code as needed
   - Re-run until checks pass

4. Commit when local checks pass:
   git add .
   git commit -m "Your message"
   git push

FOR PROJECT MAINTAINERS (CI/CD):

1. GitHub Actions automatically runs on push/PR
2. Status visible in PR checks section
3. Green checkmark = type checking passed
4. Red X = type checking found issues (review details)
5. To enforce (when ready): uncomment "Enforce type checking" in workflow
