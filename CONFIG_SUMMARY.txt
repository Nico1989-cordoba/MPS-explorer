================================================================================
CONFIGURATION SECTIONS IN DETAIL
================================================================================

ROI CONFIGURATION:
  diameter_scale_factor: 1.3
    - Scales circular ROI circle diameter
    - Range: > 0 (typically 1.0 - 2.0)
    - Larger = bigger selection circles

  extent_divisor: 10
    - Initial ROI extent = image_dimension / extent_divisor
    - Range: > 0 (typically 5 - 20)
    - Larger = smaller initial ROI

  color_rgb: [255, 0, 0]
    - RGB color for ROI outline [Red, Green, Blue]
    - Range: each 0-255
    - Examples: [255, 0, 0]=Red, [0, 255, 0]=Green, [0, 0, 255]=Blue

  z_order: 10
    - Rendering layer (higher = on top)
    - Range: 0-100
    - Typical: 10 (above most graphics)

HISTOGRAM CONFIGURATION:
  default_knn_bins: 30
    - K-NN distance histogram bins
    - Range: 5-100
    - Larger = finer resolution

  bins_2d: 400
    - 2D XY histogram bins (cluster centroid positions)
    - Range: 50-1000
    - Larger = higher spatial resolution
    - High values (>500) may be slow on older computers

  bins_z: 500
    - Z-axis histogram bins (axial distribution)
    - Range: 50-1000
    - Larger = finer axial resolution

  max_lateral_distance_nm: 800
    - Maximum lateral distance for KNN histogram x-axis
    - Range: 100-2000
    - Larger values = more spread out histogram

VISUALIZATION CONFIGURATION:
  point_size_noise: 3
    - Pixel size for noise points (DBSCAN label = -1)
    - Range: 1-20
    - Typical: 2-5 (smaller to de-emphasize)

  point_size_good_cluster: 5
    - Pixel size for good cluster members
    - Range: 1-20
    - Typical: 4-8 (medium prominence)

  point_size_centroid: 10
    - Pixel size for cluster centroids
    - Range: 1-30
    - Typical: 8-15 (largest for visibility)

TYPICAL TUNING SCENARIOS

Scenario 1: Higher Resolution Histograms

  Goal: Make centroids stand out
  Solution:

      point_size_centroid: 20      # From 10
      point_size_good_cluster: 5   # Keep same
      point_size_noise: 2          # From 3

Scenario 4: Focus on Local Clustering
  Goal: See nearby clusters clearly
  Solution:
    histogram:
      max_lateral_distance_nm: 300  # From 800
      default_knn_bins: 50          # Increase from 30

Scenario 5: Different Color Scheme
  Goal: Use green instead of red ROI
  Solution:
    roi:
      color_rgb: [0, 255, 0]  # Green (was [255, 0, 0])
