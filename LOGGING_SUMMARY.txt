================================================================================
ROTATING FILE HANDLER DETAILS
================================================================================

How It Works:
  1. Log file grows as application runs
  2. When size exceeds max_bytes (10 MB):
     - Current file → mps_explorer.log.1
     - Existing .log.1 → .log.2
     - ... continue rotation ...
     - Oldest (.log.5) → deleted
  3. New mps_explorer.log created

Benefits:
  ✅ Prevents unbounded log growth
  ✅ Preserves history (~50 MB with 5 backups)
  ✅ Automatic (no manual cleanup)
  ✅ Production-standard approach

Example File Structure:
  logs/
  ├── mps_explorer_2026-05-28.log     (current)
  ├── mps_explorer_2026-05-27.log.1   (~10 MB)
  ├── mps_explorer_2026-05-26.log.2   (~10 MB)
  ├── mps_explorer_2026-05-25.log.3   (~10 MB)
  ├── mps_explorer_2026-05-24.log.4   (~10 MB)
  └── mps_explorer_2026-05-23.log.5   (~10 MB)
